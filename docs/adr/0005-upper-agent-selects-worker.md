# 上层 Agent 选择 Run 的执行从机

CCS 从机池只回传每台从机的能力、GPU、磁盘、工作负载和可达性事实；Run 的 `worker_id` 由上层 Agent 显式选择并进入操作计划摘要。CCS 会验证所选从机、拒绝多从机请求中缺失或未知的选择，并严格路由提交与后续操作，但不会基于负载自行改派。这保持了 CCS 作为受控桥梁而非科研调度决策者的定位，也使 Agent 的选择理由可以由上层工作流独立记录和审查。

一个 Study 的不同独立 Run 可以由 Agent 指派到不同从机并行执行。单个 Run 跨多机的 NCCL、DeepSpeed 或其他分布式进程组需要独立协议和故障语义，不包含在从机池 v1 中。

## 来源等级

| basis | 含义 |
| --- | --- |
| submitted | 从该运行的spec及包装器转发规则得到的提交配置 |
| recorded | 已有启动记录，例如experiment-contract、restore-audit |
| frozen_code | 核对冻结代码及覆盖关系得到的配置，不等于实时读取进程 |
| derived | 基于已知前提计算，必须保留条件说明 |
| not_recorded | 未记录，不猜测、不以零替代 |

不同参数组可能覆盖基础lr/weight decay。启动版本不是重新探测当前环境；基础分辨率不是每批次的实际尺寸。
“来源已核对”表示该报告经代码审阅且本机来源副本哈希匹配，不代表所有参数都做了运行时内省。
报告并非数字签名的防篡改凭证；能修改本机文件的用户也能重写它。

## 实现与复核

`scripts/build_config_report.py` 对已审阅的四份冻结Python文件做版本哈希检查，仅用AST读取字面量默认值，
不会导入或执行研究代码。提交参数与启动recipe不一致、存在未支持的续训/限批覆盖或源码版本变化时拒绝生成。
这是一种明确限定适配器版本的报告生成方式，不是通用“自动理解任意模型配置”的承诺。

八份源文件仅通过一次性SCP读取，保存在：
`data/config-evidence/<run_id>/`。不更新本地原始提交配置、数据库或原始证据绑定。

```powershell
python scripts/build_config_report.py --run-id run_21eb7b7bc8cb411c873947855de413dc
```

产出configuration.json。`controller.configuration` 在看板采集周期内进行有界本地读取，
检查run_id、规范化spec SHA256、evidence绑定和源文件副本哈希。失败只隐藏配置并标明原因，不影响训练状态。
不为配置面板增加SSH轮询；浏览器请求继续只读缓存。目录没有该运行的报告时显示“未记录”。
旧任务不会套用CVFDETR参数，切换任务会清除之前的配置。

源码哈希和报告审阅只针对下载时的冻结副本；远端后续漂移仍由既有运行期证据观察器负责。
JSON导出包含配置路径与哈希，可能有未公开研究信息，不应直接公开分享。

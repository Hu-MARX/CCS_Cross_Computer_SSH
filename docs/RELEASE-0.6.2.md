# CCS 0.6.2：恢复观测与安全维护候选

状态：源码候选。不是已发布安装包，也不表示从机已升级。

## 变更

- 工作区能力协商与实际执行账号/根目录/入口一致；默认训练入口行为不变。
- 面板区分真实 stdout 步数、绑定进度报告、完整断点报告和已观测范围内重算差额。
  保留 native 指标优先；训练器 receipt 不提升为已验证恢复。
- 普通 JSON progress report 适配只读 inspect，绑定配置、Run、身份、路径和签名。
  输出间隔可声明，不把正常低频日志误按固定 90 秒判陈旧。
- 三个固定采集循环隔离目录/历史、关注 Run 的 native 观测和日志指标。
  只有本地鉴权同源 focus 偏好可改；没有远端写 HTTP 接口。
- 显示实际导入版本、启动源码摘要和磁盘变化需重启提示；不自动热加载。
- 离线升级预检独立展示 controller/CLI/daemon/workspace 角色，未知事实保持 unknown；
  side-by-side 检查表只是预览，不能替代 gateway 的精确计划确认。
- 修复验证报告将子测试错误数从父测试数直接扣除而出现负通过数的问题；
  父测试、subtest 和 fixture 计数分别报告，原始失败/错误及 skip 门禁不变。

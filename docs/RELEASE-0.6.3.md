# CCS 0.6.3：安全暂停握手源码候选

状态：源码候选，不是已发布安装包，不表示远端 worker 已升级。

## 变更

- 新增精确预演确认的 `run.pause`；请求身份、worker 和 Run 绑定，旧 worker 或未声明支持的任务拒绝执行。
- 训练器在显式优化器安全点提交完整断点和绑定 ACK，再以保留退出码 85 退出。
  supervisor 校验断点字节；只有独立 systemd cgroup 静止证据才报告安全暂停。
- process 后端的进程组清理不是完整 Run 静止证明；保持“已保存，等待完整退出确认”。
- 请求超时不强杀、不中断训练、不自动续训。v1 每 Run 只允许一个不可变请求，不支持多进程。
- `RecoveryAudit` 在 `RecoveryInput` 之后核对实际加载的七项状态摘要，并确认模型和优化器真实推进。
  它不是文件校验、跨账号认证或科学结果验收的替代品。
- 看板只读显示暂停请求、保存确认、完整退出和过期观测；不新增 HTTP 远端写入口。
- 真实 CLI 调用链明确区分发布前拒绝和发布后的 unknown，后者不能自动重发。

协议、CPU 示例和恢复边界见 [安全暂停握手](COOPERATIVE-PAUSE.md)。
